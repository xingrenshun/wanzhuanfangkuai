- **⚠ 大文件推送的坑（重要，跨项目通用）**：`git lfs push` 经 Clash Verge(7897) / WorkBuddy 沙箱代理(58904) 时，**每次都在 ~94–101MB 处被 `wsasend: An existing connection was forcibly closed` 掐断**（代理链上有单请求体积上限）。
  解法：**LFS 大对象走直连**——
  ```bash
  unset HTTP_PROXY HTTPS_PROXY http_proxy https_proxy
  export NO_PROXY="*"
  git -c http.proxy= -c https.proxy= lfs push --all origin   # 直连 7.5MB/s，26 秒传完 134MB
  git -c http.proxy= -c https.proxy= push -u origin main
  ```
  本地 git 全局配置里的 `http.proxy=http://127.0.0.1:7897` 与 shell 的 `HTTP_PROXY` 是两套，必须**都清掉**才真正直连。
